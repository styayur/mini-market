# Security Policy

## Supported version

Security fixes target the current `main` branch and the latest published GitHub Pages deployment.

## Report privately

Do not report exploitable issues in a public issue. Use GitHub private vulnerability reporting:

https://github.com/styayur/mini-market/security/advisories/new

Include the affected route, browser/OS, reproduction steps, impact, and any proof-of-concept details needed to verify the report. Remove private browser data and unrelated screenshots.

## Scope

Relevant issues include cross-site scripting, unsafe URL handling, dependency compromise, accidental collection of sensitive data, privacy leakage, and static-export deployment integrity.

Mini Market is a local browser prototype. Tokens, wallet balances, purchases, receipts, and future concepts are simulated in browser storage and have no financial or contractual value.
